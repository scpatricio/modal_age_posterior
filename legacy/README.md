# Legacy code

`estimation_algorithm_arxiv_v1.R` is the code of the first version of the method (arXiv:2411.09800, v1, 2024), which modeled death counts with a multinomial distribution and used a Gaussian approximation. It is kept for reference only. The current method, which models death counts as Poisson given the death rates and exposures, is in `../Code/` and is described in `../Manuscript/`.
